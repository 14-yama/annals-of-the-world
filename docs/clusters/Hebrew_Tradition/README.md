## Separation of concerns for interfaces
- Both Early_Christianity and Jewish–Islamic_Intellectual_Exchange are standalone cluster trees. They are not nested under Hebrew_Tradition; link via cross‑references only.
- Parent roots
  - Early_Christianity (D) under Christian_Tradition (D). Interface to Hebrew_Tradition (Second_Temple) via edges like EMERGES_FROM (M→E/D), INTERPRETS (T↔T/D), DISPUTES (P↔P/M↔M), SPLITS_FROM (M→M).
  - Jewish–Islamic_Intellectual_Exchange (D) under Islamic_Thought (D) or Interreligious_Exchange (D). Interface via TRANSLATES; COMMENTATES_ON; CITES; CORRESPONDS_WITH; STUDIES_UNDER; INFLUENCES.
- Node reuse, not duplication: persons, texts, institutions exist once globally and can appear in multiple clusters. Clusters are curated views over the same nodes/edges.
- Crosslink mechanics: put cross‑cluster edges in an “Interfaces” section of the source cluster; do not move ownership of nodes. Optionally tag edges (crosslink=true, interface="Second_Temple"/"Medieval").
- Boundary example: Paul_of_Tarsus belongs to Early_Christianity; references from Hebrew_Tradition occur only as interface edges (e.g., DEBATES, INTERPRETS), not by relocating the node.
