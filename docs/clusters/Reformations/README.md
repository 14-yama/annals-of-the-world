# Reformations Overview

This index groups all Reformation clusters, links to each, and outlines a mini‑taxonomy of streams.

## Taxonomy

- Magisterial Reformations
  - Lutheran: German_Reformation; Scandinavian_Reformations; Polish_Lithuanian_Reformation (parts)
  - Reformed (Calvinist): Swiss_Reformation; Dutch_Reformation; French_Reformation; Scottish_Reformation
- Radical Reformation
  - Anabaptist/Spiritualist: Radical_Reformation (interfaces with Swiss/German)
- Precursor/Parallel
  - Bohemian_Moravian_Reformation (Hussite/Utraquist → Unitas Fratrum)
- Catholic Reformation / Counter‑Reformation
  - Catholic_Reformation (responses, renewal, missions)
- National Settlement with distinctive via media
  - English_Reformation
