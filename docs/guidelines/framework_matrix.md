# Framework Matrix

Purpose: help curators pick appropriate verbs when linking content nodes to each other and to Framework lenses.

Matrix (Framework → Recommended verbs)

| Framework | Recommended verbs | Notes |
|---|---|---|
| CAUSE_AND_EFFECT | CAUSES, ENABLES, TRIGGERS, TRANSFORMS | Use for direct causal chains and technological/ideational impacts |
| CULTURAL_DIFFUSION | DIFFUSES, INTRODUCES, ADAPTS, ADOPTS | Use when tracking transmission across regions or traditions |
| DOCTRINE_DEVELOPMENT | CANONIZES, SYSTEMATIZES, STANDARDIZES, INTERPRETS | For formalization of doctrines, legal/ritual consolidation |
| TEXTUAL_TRANSMISSION | TRANSMITS, TRANSLATES, PRESERVES, EDITS | For copying, translation, editorial activity and textual lineage |
| LEGAL_INTERPRETATION | INTERPRETS, CODIFIES, REFORMS, REJECTS | Use for jurisprudential or canonical rulings and their effects |
| RITUAL_STANDARDIZATION | STANDARDIZES, INSTITUTES, REGULATES | For liturgical and ritual codification across communities |
| GEOPOLITICAL_LINKAGE | LINKS, CONNECTS, RECONFIGURES | For imperial, diplomatic, or territorial reorganizations impacting nodes |
| CONFLICT_AND_RESOLUTION | CAUSES, RESOLVES, RADICALIZES, RECONCILES_WITH | For schisms, wars, reconciliations and settlements |
| ADAPTATION | ADAPTS, TRANSFORMS, REINTERPRETS | For contextual reinterpretations and cross-cultural adaptations |
| TEMPORAL_LINKAGE | PRECEDES, FOLLOWS, IS_ANTECEDENT_TO | For ordering, periodization, and retrospective linking |

Usage note

- When applying a Framework lens, prefer verbs from the mapped row. If none fit, propose a new verb via the [relations_vocabulary.md](./relations_vocabulary.md) proposal process.

End of framework matrix (draft).
