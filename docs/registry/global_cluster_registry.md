## Adding a New Country to the Registry

1. Create `geo-registry/places/countries/<slug>/index.json` from template
2. Add country section to this registry under appropriate Continent → Region
3. List planned clusters with timeframes
4. Update summary table counts

See [global_cluster_management.md](./global_cluster_management.md) for detailed workflow.
