# Audit Reports

Machine-written reports from the git-first audit pipeline.

Each file is regenerated by the corresponding GitHub Actions workflow that walks
`data/appwrite-export/entities/` locally — **zero Appwrite reads**.

| File | Producer | Schedule |
|------|----------|----------|
| `completeness.json` | `scripts/audits/completeness.py` | Daily |
| `orphans.json` | `scripts/audits/orphans.py` | Daily |
| `consistency.json` | `scripts/audits/consistency.py` | Daily |
| `duplicates.json` | `scripts/audits/duplicates.py` | Weekly (Sun) |
| `classification.json` | `scripts/audits/classification.py` | Weekly (Sun) |
| `stats.json` | derived from JSON walk | Daily |

Frontend reads these committed JSON files (Vite static fetch) and falls back to
the Appwrite `audit_log` collection for live edit history.

See `docs/governance/git_first_bots.md` for full architecture.
